# Particle Saturn

基于 Three.js 和 MediaPipe 实现的交互式粒子土星可视化项目，通过摄像头捕捉手势，实时操控由粒子构成的三维土星。

### 在线体验

**[在线演示](https://saturn.bugstack.top/)**

### 功能特性

- 使用 Three.js 和 WebGL 渲染三维粒子土星及动态星空。
- 基于 MediaPipe 实现实时手部追踪。
- 通过拇指与食指的距离控制土星缩放，通过手掌位置调整观察角度。
- 无手势输入时自动进入巡航展示模式。

### 使用说明

访问在线演示页面并允许摄像头权限，即可通过手势进行交互。建议使用支持 WebGL 的桌面浏览器。
